# 3DLabs 제안 덱 — 드론대장 붕붕이

`붕붕이_3DLabs_제안.pptx` (35장, 16:9 와이드, 맑은 고딕). 같은 내용의 PDF 미리보기 포함.
v4는 구조를 개편한 판: 기업이 겪는 문제를 먼저 말하고(업체 데이터 오류 강조), 과제와 이틀의 과정, 실제 촬영을 보인 뒤
기술 소개(검증 수치 없이) → 검증(긍정 표현, 한계 삭제) → 기대효과·제안 → 한 장 요약 순서다.
업체 저장소(dohun415/aerodrone_hackathon)의 실제 결과와 10-02 결정 사항을 반영한다.
발표 전 결정·보완 목록은 `미해결_과제.md`.

## 다시 빌드하기

```bash
cd deck
npm install pptxgenjs react react-dom react-icons sharp
NODE_PATH=$PWD/node_modules node build.js
```

`build.js` 끝의 `applyTheme`는 Claude pptx 스킬의 `scripts/apply_theme.js`를 쓴다(테마 색을 파일에 기록).
그 파일이 없으면 해당 줄을 지우고 빌드해도 열리지만, 스킴 색이 Office 기본 팔레트로 보인다.
그림은 `deck/img/`(업체 저장소 figures 축소본, 조석 모델 프레임, OpenDrift 지도)에서 읽는다.

## 팀이 채워야 할 것

- 12장 "이틀의 과정": 줌 회의 날짜·횟수(출처 줄에 표시).
- 18장 촬영 거리 표는 4K·24 mm 상당 화각 기준 계산값. 실제 기체 스펙으로 확정.
- 무게 비교(6·26장)의 기준값은 '정답 부피 × 가정 밀도'. 저울 실측이 오면 문구와 그림 11·12를 교체.
- 8장 처리 단가(톤당 약 50만 원)와 국비:지방비 50:50은 공개 보도 기준. 팀 조사값으로 바꾸려면 `stat(...)` 수정.
- 5·6장 제목 후보는 발표자 노트에 적어 두었다. 마음에 드는 것으로 교체.
