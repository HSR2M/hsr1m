## 오탐을 줄인 방법 (17장·25장의 근거)

| 겹 | 코드 | 규칙 |
|---|---|---|
| 학습 | `litter/seg.py prepare(neg_keep=0.15)` | 쓰레기 없는 타일 15 %를 음성 표본으로 섞고 운용 해상도(2~4 cm/px)로 축소 학습 |
| 타일 병합 | `litter/seg.py predict(merge_ios=0.6)` | 1024 타일 겹침 0.2, 가장자리 박스 점수 ×0.8, 같은 클래스 IoS ≥ 0.6 병합 |

## 반영한 수정 (10-02 검증 보고서)

- 발생량 14.5만 t은 2018년 KMI 추정·초목류 포함으로 표기, 현존량 15.2만 t(1차 출처 미확인)은 삭제하고 해안쓰레기 비중 76 %로 교체.
- 지자체 처리 비중 90 % → 약 87 %(직할기관 13.0 % 제외), 국비:지방비 50:50은 "2018 보도 기준, 사업별로 다름", 처리 단가는 2018~19 보도로 연도 표기, 금액은 가정 계산임을 명시.
- 경남 1,180 t: 초목류가 대부분임을 본문에, "3주"는 "약 25일(8/15→9/9)"로.
- 101 kg: 서비스 demo-mungap 산출(원본 사진·DSM·실측 없음)임을 출처에, 15~1,328 kg(밀도 범위)과 115~1,355 kg(두께 범위)을 구분.
- 재방문 +697 m는 "재방문 몫 697 m, 총 1,718 m(커버리지만 679 m)"로, 라벨 7개(5/7→6/7) 표본 크기 표기.
- 문갑도 62 %는 형상 점수(만입도·노출·띠 폭) 기준으로, 니하우 25 %는 "같은 길이 30 % 기준 지리 순서"로, 인천 99 %는 "모델 자체 분포 기준"으로.
- "50 m가 1 m대로" → "수 m로(상대 1 m대, 절대 GPS 약 5 m)".
- 8개 무역항 드론 모니터링(2018 사업) 삭제, KOEM-ARK(2026.07)와 전남 AI·드론 연안관리(2026.05)로 교체, 441억 중 부표 342억 명시, 경쟁 사례 대비 차별점 한 줄.
- 로드맵 "2026 4분기" 일정은 지원 장으로 통합(일정 대신 "지원 후 1분기 안에 현장 1회").

NODE_PATH=$PWD/node_modules node build.js
