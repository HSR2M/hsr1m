`붕붕이_3DLabs_제안.pptx` (23장, 16:9 와이드, 맑은 고딕). 같은 내용의 PDF 미리보기 포함.

구성: 표지 · 한 장 요약 → 01 현황과 문제(수거량 추이, 비용 구조, 거제 사례, 현행 방식 한계, 문갑도 1.3 kg vs 101 kg)
→ 02 솔루션(7단계 파이프라인, 핫스팟 경로, 비행 조건, 탐지·삼각측량, 부피·예측구간, 수거계획 대시보드, 수거 경로)
→ 03 검증(요약표, 한계와 대응) → 04 제안(위성·드론·지자체 결합, 로드맵, 요청사항).

## 다시 빌드하기

```bash
cd deck
npm install pptxgenjs react react-dom react-icons sharp
NODE_PATH=$PWD/node_modules node build.js
```

`build.js` 끝의 `applyTheme`는 Claude pptx 스킬의 `scripts/apply_theme.js`를 쓴다(테마 색을 파일에 기록).
그 파일이 없으면 해당 줄을 지우고 빌드해도 열리지만, 스킴 색이 Office 기본 팔레트로 보인다.
그림은 `deck/img/`가 없으면 `site/assets/`에서 읽는다.

## 바꿔야 할 것

- 15장 대시보드의 수치는 예시 데이터. 문갑도 42개 라벨이 오면 `kp`, `segs`, 후보 표를 실제 값으로 교체.
- 6장 거제 수치(437 t → 272 t, 8천만 원)는 원본 기획안이 인용한 뉴시스 2023-07-25 기사 기준.
- 5장 처리 단가(톤당 약 50만 원)와 국비:지방비 50:50은 공개 보도 기준. 팀 조사값(48만 원·시군 25%)으로 바꾸려면 `stat(...)` 두 곳 수정.
