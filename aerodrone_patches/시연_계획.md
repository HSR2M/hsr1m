# 실내 시연 계획 — "날리고, 재고, 저울로 확인한다" (2026-10-02)

## 0. 지금 계획에 대한 판단
- 해류 영상: 분위기용 10초면 충분. 우리 성과가 아니라 중심에 두면 손해.
- 모형 섬 주변 비행 + 미리 만든 지도: **비행과 결과가 끊어져** 있어 "녹화 재생"으로 보인다. 심사위원은 "그 비행이 그 결과가 됐다"를 봐야 점수를 준다.
- 실시간성은 두 곳에서 되찾을 수 있다. ① 비행 중 화면에 **라이브 탐지**(이미 만든 scrcpy 미러링 + YOLO) ② **심사위원이 직접 조종하는 가상 비행**(시뮬 수동 모드, 이번 패치).
- 가장 센 장면은 **저울**이다. 화면의 추정 무게와 저울 숫자가 나란히 서는 순간.

## 1. 무대 구성 (3개 화면)

| 큰 TV/빔 | 비행 중: 폰 화면 미러링 + 라이브 탐지(박스·개수). 비행 후: 점구름 → 치수 → 무게 → 작업카드 | 발표자 |

소품: 섬 모형(탁자 위), 실제 쓰레기(스티로폼 조각·부표·로프·페트병·종이상자), **크기 아는 상자 1개**, 1 m 기준 막대, **저울**, 프롭가드, 안전망 또는 테이프 경계, 출력한 작업카드·비행 점검표, QR 코드.

## 3. 실내 비행이 되게 하는 조건 (코드 패치 포함)
- 실내는 GPS가 없다 → SRT에 위경도가 없거나 0으로 찍힌다. 이번 패치의 `--origin LAT,LON`으로 3D 좌표를 **문갑도 좌표에 올려** 지도에 핀을 찍는다(모형 섬 = 문갑도). orbit_map·objvol 둘 다 같은 값.
- 상대고도는 **이륙점 기준**이다. 바닥에서 떠서 탁자 위 모형을 돌면 축척이 탁자 높이만큼 틀어진다 → **모형 바닥면에서 이륙**하거나 `--alt-offset 0.75`(탁자 높이).
- 기체 위치 유지(VPS)는 바닥 질감·조명이 필요하다. 모형 주변에 무늬 있는 천을 깐다. 프롭가드 필수, 사람과 2 m 이상.
- 비행 직후 처리 명령(리허설에서 시간 측정해 둘 것):
```powershell
python -m litter.orbit3d  --video D:\DCIM\...\DJI_xxxx.MP4 --srt ...SRT --n 60 --out runs\demo\orbit
python -m litter.orbit_map --orbit runs\demo\orbit --srt ...SRT --litter runs\seg\aihub_gsd_det_s\weights\best.pt --out runs\demo\map --origin 37.2186,126.1150 --alt-offset 0
# 조밀(빠른 설정, GPU 3분) → fused.ply
python -m litter.objvol --orbit runs\demo\orbit --srt ...SRT --ply C:\work\demo\dense\fused.ply --objects runs\demo\map\objects.csv --out runs\demo\objvol --origin 37.2186,126.1150 --truth "상자태그:60x45x12"
python -m litter.fromvideo run --objvol runs\demo\objvol\objvol.json --objects runs\demo\map\objects.csv --material "..." --out runs\demo\plan
```
- 실내 비행은 항공안전법 비행승인 대상이 아니다. 대신 주최 측 허가와 안전(프롭가드·경계·안전망)을 말할 것. 교수님들은 이걸 본다.

## 4. 심사위원 체험 (시뮬 수동 모드)
```powershell
python -m litter.sim_ortho --name judge1 --model aihub --manual --device 0 --hide-labels --alt 20 --alt_low 8
```
- W/A/S/D 이동, Q/E 기수, R/F 고도, **V = AI 재방문**, H = 호버 촬영, ESC 종료. 창에 드론 시점 + 미니맵.
- `--hide-labels`로 정답 라벨을 숨기고, 끝나면 summary.json의 재현율을 바로 보여준다 ("당신 비행의 재현율 0.7").
- GPU면 초당 10프레임 이상, CPU면 3~5. 리허설에서 `--imgsz 640`으로 낮추면 더 빠르다.
- 키보드 대신 USB 게임패드를 쓰려면 JoyToKey류로 WASD에 매핑(설치 1분).

## 5. 시각적으로 더 센 것 (여력 순)
1. **점구름 회전 애니메이션**: viewer.html에서 243만 점 + 카메라 궤적이 돌아가는 10초. 치수 선과 숫자 오버레이.
2. **라이브 탐지 카운터**: TV 상단에 "탐지 12 · 추정 0.8 kg · 마대 1" 숫자가 비행 중 올라가게(live.py HUD에 한 줄).
3. **저울 클로즈업**: 폰 카메라로 저울 눈금을 TV에 미러링.
4. **프로젝터로 모형 위에 지도 투영**: 처리 결과 핀을 탁자 모형 위에 직접 쏜다. 4점 보정 30분. 여력 있을 때만.
5. 전후 슬라이더(수거 전/후 정사영상)는 이번엔 생략.
