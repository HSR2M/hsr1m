# 인천·강화 해역 해류 데이터 출처와 쓰레기 집적 계산 근거

## 1. 대상 해역의 특징
* 영역: 동경 125.85–126.95°, 북위 37.05–37.95° (덕적도–인천–송도–시화, 강화도·교동도·석모도, 한강하구·조강, 김포, 임진강 하류).
* 인천항 조차 최대 약 9 m(대조차), M2 분조 진폭 약 2.9 m, S2 약 1.1 m. 조류가 유동의 대부분을 차지하고
  염하수로·석모수로·인천항 접근수로에서는 대조기 최대 2 m/s 이상.
* 한강·임진강·예성강이 조강(한강하구)으로 합류해 경기만으로 빠져나가며, 여름 장마철 홍수 때 육상 쓰레기가 집중 유입.
* 세계적 규모의 갯벌(강화 남단, 영종도 북·서안, 인천·송도, 대부도·시화)이 쓰레기를 가두는 역할.

### 2.3 자료 선택 기준
* 좁은 수로(염하수로 폭 수백 m)를 보려면 격자 ≤ 200–500 m 가 필요 → 전지구 모델(8 km)은 외해 흐름 참고용.
* 조류의 시간 변화를 영상으로 보이려면 **시간별** 자료(CMEMS PT1H, 조석 모델)가 필요. 일평균 자료는 조류가 평균되어 사라짐.
* 쓰레기 장기 이동은 **잔차류**(조석 평균 흐름)가 결정 → 조석 모델 단독보다 하천·바람을 포함한 순환모델(KOOS/CMEMS)이 유리.

## 3. 쓰레기가 모이는 곳을 계산하는 방법과 근거

### 3.1 입자추적 방정식
부유 쓰레기 입자 i 의 위치 **x**_i 는 다음 확률미분방정식을 따른다.

    d x_i / dt = u(x_i, t) + c_w · W_10(t) + sqrt(2K) · ξ(t)

* u: 표층 해류(조류 + 잔차류), W_10: 10 m 바람, c_w: 풍압계수(부유물 형태에 따라 0.01–0.03; 수면 위 노출이 큰 스티로폼·페트병은 큼),
  K: 수평 난류확산계수(연안 1–50 m²/s), ξ: 백색잡음.
* 시간적분은 4차 Runge–Kutta(이 저장소 dt = 5분), 유속은 격자에서 이중선형 보간.
* 동일한 방법이 OpenDrift(노르웨이 기상청), OceanParcels(위트레흐트대), TrackMPD 등 공개 도구에 구현되어 있다.

### 3.2 좌초(beaching)·재부유(resuspension)
* 입자가 해안 셀에 닿으면 확률 P_B 로 좌초(이 저장소 기본 0.10, 하천 제방 구간 0.03), 좌초 입자는 하루 P_R 확률로 재부유(0.20, 하천 0.5).
* 문헌에서는 "해안 접촉 시 좌초 시간규모 λ_B ≈ 1–10일, 재부유 시간규모 λ_R ≈ 수십 일"로 매개변수화한다(Onink 등 2021 류의 전지구 연구).
  대조차·광역 갯벌 해역은 좌초가 잦고 재부유는 대조기에 집중되므로 P_R 을 작게 둔다.
* 매개변수는 KOEM 모니터링 지점별 쓰레기량과 모델 좌초량의 상관이 최대가 되도록 보정하는 것이 원칙이다.

### 3.3 집적 지표(어디에 "많이 모이는가")
1. **해안 좌초 밀도** D(s) [개/km]: 해안선 위치 s 주변 σ ≈ 1 km 가우시안 커널로 평활한 좌초 입자 수.
   상위 15 %(설정값) 구간을 집적 예상 해안으로 정의하고 빨간 반투명 라인으로 표시한다. 라인의 진하기는 D 에 비례.
2. **해상 체류 밀도** ρ(x): 마지막 15일 동안 부유 입자의 시간평균 밀도. 상위 5 % 등고선(점선)은 해상에 떠 있는 상태로 모이는 곳.
3. **잔차류 수렴역**: 조석 2주기(≈24.8 h) 동안 격자 모든 점에서 출발한 추적자의 순변위/시간 = 라그랑주 잔차류 u_res.
   ∇·u_res < 0 인 곳(수렴)에 부유물이 모인다. 이는 "표층 수렴역에 부유물이 모인다"는 고전적 원리(Stommel 1949, Langmuir·전선·와류 수렴)에 근거한다.
4. (선택) **체류시간**: 입자가 영역/해역 구획에 머문 평균 시간. 길수록 집적 가능성이 큼.

### 3.4 물리적 근거 요약
* **조석 비선형성**: 대조차 해역에서는 조류가 왕복하지만 유속장이 공간적으로 변하므로 입자는 Stokes 드리프트·조석 정류에 의해 순이동한다.
  수로 끝·섬 뒤·만 안쪽에는 잔차 와류와 정체역이 생겨 부유물이 모인다.
* **하천 플룸**: 한강 홍수 시 담수 플룸이 조강→석모수로·염하수로→경기만으로 퍼지고 플룸 전선(수렴대)에 쓰레기가 줄지어 모인다.
* **바람**: 여름 남서풍은 쓰레기를 북동쪽(강화 남안·영종 서안·인천 연안)으로, 겨울 북서풍은 남동쪽(영흥·대부·시화)으로 민다.
  바람을 맞는 해안(windward shore)에 집적이 큼.
* **갯벌과 해안 형태**: 완경사 갯벌·오목한 만·방조제 모서리·수로 입구는 유속이 약해 좌초가 잦고 재부유가 적다.
* **관측 사례**: 국내 모니터링에서 한강 기원 쓰레기가 강화 북·동안(조강·염하수로), 강화 남단·서안, 영종·장봉·신도·시도, 덕적군도까지 도달함이 보고되어 있다.
  이 저장소의 모의도 같은 큰 그림(한강 하구 → 강화 주변 → 외해 도서)을 재현한다.

## 4. 이 저장소의 조류 모델(실측 자료가 없을 때)
수심 적분 연속방정식 ∂η/∂t + ∇·(h u) = R 에 비회전 흐름 u = −∇Φ 를 가정하면

    ∇·(h ∇Φ) = ∂η/∂t − R

* η(x,y,t) = Σ_k A_k(x,y) cos(ω_k t − φ_k(x,y)), k ∈ {M2, S2}. 외해 진폭 2.5 m → 내만 3.0 m, 위상 지연은 얕은물 파속 c = √(gh) 로
  개방경계에서의 최소 전파시간(Dijkstra)에 0.6 을 곱한 값(경기만은 부분 정상파).
* h: 해안거리 기반 수심 모형(1.5–32 m) + 주요 수로(염하·석모·인천항·조강) 최소 12 m, 하천 6 m. GEBCO 로 교체 가능.
* R: 한강(기본 2,000 m³/s, 2–7일차 홍수 펄스 최대 12,000 m³/s)·임진강(400 m³/s) 유입. 개방경계(서·남) Φ = 0.
* 선형 문제이므로 (M2 cos, M2 sin, S2 cos, S2 sin, 하천) 5개의 정상해를 희소 LU 로 한 번 풀고 임의 시각 유속을 합성한다(0.2초/시각).
* 관성·코리올리·마찰 생략 → 1셀 폭 틈새의 비현실적 유속은 평활·2.5 m/s 상한으로 억제. 결과 유속: 외해 대조기 0.8 m/s, 염하수로 2.5 m/s, 인천항 접근 1.3 m/s.

## 5. 영상 제작 방법 (실측 자료 사용 시)
1. `pip install -r requirements.txt` (파이썬 3.10+, ffmpeg 필요).
2. 배경 위성지도: `python -m incheon_debris_sim.fetch_data basemap` (Esri) 또는 `--source eox`.
3. 해류: `fetch_data hycom` / `fetch_data cmems` 로 NetCDF 를 받거나, TPXO/FES 조화상수를 pyTMD 로 u,v 격자 시계열 NetCDF 로 변환.
   국립해양조사원 지점 조류 관측치로 모델의 진폭·위상·유속을 검증.
4. 수심: GEBCO 영역 NetCDF 를 받아 `geodata.load_external_depth()` 로 사용(조류 모델을 쓸 때).
5. `python run_all.py --nc data/currents.nc` → `output/incheon_debris_simulation.mp4`.
6. 검증: `output/hotspots_ranked.json` 의 순위를 KOEM 모니터링 지점(강화·영종·덕적 등) 쓰레기량과 비교하고 `config.py` 의
   `P_BEACH`, `P_REFLOAT_PER_DAY`, `WINDAGE`, 발생원 비율을 조정.

다른 도구로 만들 때: OpenDrift(`OceanDrift` 모델 + CMEMS reader + `stranding` 옵션)로 입자추적 → 결과 NetCDF 를 QGIS 시계열 플러그인이나
Blender/matplotlib 로 위성지도 위에 애니메이션. 웹 지도에서는 leaflet-velocity 로 유속장 스트리크를 그릴 수 있다.
