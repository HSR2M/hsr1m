# incheon_current_sim — 인천 앞바다 조류 흐름 시뮬레이션

인천·경기만 일대에서 조석(M2, 주기 12시간 25분)에 따라 **창조류(밀물)와 낙조류(썰물)가 되풀이되는 모습**을
간략화한 해도 위에 입자 애니메이션으로 보여주는 단일 HTML 페이지다. 서버나 설치가 필요 없다.

```
index.html   브라우저에서 바로 열면 된다 (더블클릭 또는 file:// 로 열기)
```

## 화면 구성

- **해도**: 강화도·교동도·석모도·영종도·무의도·장봉도·영흥도·대부도·덕적도·자월도와 김포~안산 육지를 손으로 단순화한 다각형으로 그렸다.
  위경도 0.2° 격자, 10 km 축척, 북쪽 표시가 들어 있다.
- **입자**: 물 입자가 흘러가는 방향으로 움직이며 유속(0 ~ 1.2 m/s 이상)에 따라 5단계 색으로 구분된다.
- **조석 패널**: 한 주기의 조위 곡선과 유속 곡선, 현재 위상(저조 정조 → 창조류 → 고조 정조 → 낙조류), 주기 내 시각, 염하수로 유속, 반복 횟수.
- **조작**: 재생/일시정지, 한 주기 재생 시간(10~120초), 입자 수(500~8000), 자취 길이, 유향·유속 화살표 격자 표시.
- **툴팁**: 바다 위에 마우스를 올리면 그 지점의 위경도, 유속(cm/s), 흘러가는 방향(16방위)이 나온다.
- 밝은 테마와 어두운 테마를 모두 지원하며, 동작 줄이기 설정이 켜진 환경에서는 일시정지 상태로 시작한다.

## 모형 설명 (실측 자료가 아님)

- 해안선, 수로 위치, 유속 크기는 모두 **개략적인 손 입력 값**이다. 실제 해류 관측·수치모델 결과가 아니다.
- 경기만의 정상파 성격을 반영해 **고조·저조 때 정조**, **중간 조위에서 유속 최대**가 되도록 유속 ∝ sin(ωt), 조위 ∝ −cos(ωt)로 두었다.
- 수로별 최대 유속: 염하수로 1.7 m/s, 조강(한강 하구) 1.3 m/s, 외해 접근 수로 1.1 m/s, 석모수로·영종 북쪽 수로 0.9 m/s, 남쪽 수로 0.8 m/s, 배경 외해 0.45 m/s.
  각 수로는 중심선에서 멀어질수록 가우시안으로 영향이 줄고, 해안 가까이에서는 유속을 줄였다.
- 한강 담수 유출을 조강·염하 방향으로 약한 잔차류(−0.25, −0.15 m/s)로 더해 낙조가 창조보다 조금 세다.
- 입자 이동 거리는 보기 쉽게 과장되어 있다. 한 주기 재생 시간을 바꾸면 조석 시계와 입자 속도가 함께 바뀐다.

## 수정 포인트

`index.html` 안의 `LAND`(해안선 다각형), `LABELS`(지명), `CH`(수로 중심선·최대 유속·폭·잔차류) 배열만 고치면
다른 해역이나 더 정밀한 해안선으로 바꿀 수 있다. 격자 해상도는 `NX`로 조절한다.
